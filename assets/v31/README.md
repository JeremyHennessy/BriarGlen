- `warden-bow.svg` — Briar Warden with bow
- `warden-staff.svg` — Briar Warden with staff
- `briar-wolf.svg` — Briar Wolf combat silhouette
- `hollow-boar.svg` — Hollow Boar combat silhouette
- `emberback.svg` — Emberback boss silhouette

Briar Glen service/town family:
- `alden.svg` — Alden the Smith
- `rowan.svg` — Rowan the Trader
- `mira.svg` — Mira the Alchemist
- `tessa.svg`, `orin.svg`, `maeve.svg`, `perrin.svg` — visible Briar Glen townfolk

The runtime treats every source as presentation only. Existing player/enemy/NPC/service coordinates, hitboxes, HP, AI/tactics, telegraphs, damage, weapon behavior, movement, interactions, collisions, progression and saves remain authoritative.

# Briar Glen authored environment assets

These files are original Briar Glen look-development assets introduced through the Build 24.1 browser proof and promoted into the Build 25 Briar Glen art rollout.

Current browser sources:
- `cottage-authored.webp`
- `tall-tree-authored.webp`
- `pine-tree-authored.webp`

Provenance: generated specifically for Briar Glen in the project ChatGPT session on 2026-08-16 from the project look-development direction, then re-encoded locally as alpha-enabled WebP for browser compatibility. They are not third-party asset-pack files.

The earlier palette-PNG proof files are retained as historical rollback/debug evidence and are not loaded by the production renderer.

Status: **user-approved Warden House hero-cluster assets / Build 25 production presentation**.

Build 25 loads the approved authored Warden House cottage and two nearby trees by default. `?canvasArt=1` restores the prior Build 23 Canvas presentation for A/B comparison and emergency visual rollback. Gameplay entities, collision, saves, progression, economy, combat and UI remain authoritative and unchanged by the authored presentation layer.

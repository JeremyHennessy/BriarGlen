# Build 30 — Copper & Ember authored prop family

These assets are original SVG artwork created specifically for Briar Glen Build 30. They contain no third-party source art, fonts, linked images, or external dependencies.

Files:
- `hollow-rock-authored.svg` — layered quarry stone with a restrained Copper seam
- `dead-tree-authored.svg` — leafless, twisted Hollow tree silhouette
- `copper-ore-authored.svg` — readable interactable Copper node
- `den-rock-authored.svg` — dark basalt formation with heat fissures
- `ember-cluster-authored.svg` — small charcoal/ember cluster for Emberback Den

The Build 30 runtime uses these only as transparent presentation overlays on existing world objects/resources. Existing coordinates, depth, collisions, interactions, resource state, combat, progression and saves remain authoritative and unchanged.
